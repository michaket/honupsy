# honupsy 0.1.0

* First public release.
* Imports and validates ANQ adult inpatient psychiatry data for measurement year 2022.
* Supports MB, MP, PH, PB, and FM records.
* Provides unit assignment, HoNOS severity summaries, composition summaries, and occupancy/capacity summaries.
* Adds tests for HoNOS missing-data handling, occupancy reconstruction, capacity estimation, and trailing empty fields in text imports.
